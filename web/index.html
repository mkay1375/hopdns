Choose what takes the hop.

DNS selects the route. HopDNS relays supported HTTP and HTTPS connections.

Routing mode

Both modes relay HTTP/HTTPS only. DNS settings cannot route UDP gameplay, direct IP connections, or all device traffic.

Saving restarts the relay and closes active connections. Device DNS caches may take time to expire.

Bring your device along.

Set your Xbox, PlayStation, or other device’s DNS server to the reachable IPv4 address above. Leave a secondary DNS blank or use another HopDNS instance; a normal resolver can bypass the relay.

Before sharing a server

Allow only trusted client addresses through your server firewall on DNS (53 UDP/TCP) and proxy ports (80/443 TCP). Keep the web panel private.
